HER LITTLE HOUSE RULES

手账的小规矩。

检测间隔

每轮结束后等待所选间隔，避免请求重叠。

记录 IPv6

分别记录 IPv4 与 IPv6，不把 IPv6 不可用算成地址变化。

IP 变化时通知

系统通知只提示变化，不展示完整 IP。

开机后在后台启动

关闭窗口后仍保持托盘观测；从托盘菜单退出应用。

CLI 探测路由

只影响本工具的探测，不改变电脑、VPN 或 Claude 配置。

支持 HTTP CONNECT / HTTPS 代理。Claude Code 不支持 SOCKS 代理；Clash 的 mixed-port 通常也接受 HTTP。含认证的代理配置使用系统加密存储。
