NW-02 启动握手修正

复核 Windows 随机启动超时同时发现一个时序缺口：主进程在 spawn 事件立即发送 init，而 ESM 后台模块可能尚未完成导入与监听注册。改为工作进程注册监听后发送 listening，主进程收到后再初始化；初始化异常明确上报并进入有限重启。批量演示事务与握手一并进入最终构建复验。
