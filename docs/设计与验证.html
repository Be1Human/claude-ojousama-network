负责人：主代理。状态：进行中；macOS 本机实现和源应用验证阶段完成，公开发布与跨平台 CI 待验证。

技术栈：Electron 45 / Node 24 / 内置 SQLite；独立 utilityProcess，托盘单实例、关闭隐藏、可选启动项；无 Python 依赖。5 类观测路径、IP/GeoIP 历史、两目标 HTTPS 曲线、CSV、私有代理加密与终端环境白名单采集。

图稿顺序：V1 原方案 → V2 二次元修订 → 下方真实应用演示截图。截图均仅含 RFC 5737 演示 IP，不是实测网络证明。

验证：npm test 核心逻辑；npm run test:ui Electron 导航、筛选、IP 隐藏、设置、暂停/继续、关闭到托盘与恢复已通过；npm run test:live 只保留脱敏结论：IPv4/认证和 API 域名 trace 成功、IPv6 DNS 失败按失败记录、GeoJS 回退成功、SQLite integrity_check=ok。没有登录或模型调用。

测试中发现并修复：ESM 顶层等待 app.whenReady 导致启动死锁；改为异步启动函数。代理失败不直连回退、IPv6 规范化、缺少目标的批次不算整条线路掉线。UI 操作在本项目 Electron 窗口内自动化执行，不依赖外部 app 的 AX。

下一步：公开仓库，macOS Apple Silicon / Intel、Windows x64 CI 构建和打包后 UI 测试，通过后发布。真实重启启动项、整夜运行和物理设备休眠仍不在当前验收范围。
