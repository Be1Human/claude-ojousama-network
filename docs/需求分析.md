# 大小姐的网络手账

面向 Claude Code 用户的独立 macOS / Windows 托盘应用。公开发布；原创同人风格，与 Anthropic 无隶属关系。

- 先生成视觉方案，再实现奶油白、陶土色与原创成年大小姐插画的桌面界面。
- 持续记录公网 IPv4 / IPv6、时间、GeoIP 国家/城市/ASN、来源和 IP 变更。失败和缺口不计为变更；本地持久化、CSV 导出。
- 根据 Claude Code 代理环境与用户明确选择的配置，探测 CLI 可能出口；分别检查认证网站和 API 的 HTTP 可达性。不能获取或保证真实登录请求的服务端源 IP；不登录、不读取账号令牌、不发送模型请求。
- 分开呈现：系统网络、CLI 代理环境、浏览器登录段。路由按目标域名分流时，第三方回显可能与目标不同。
- 后台常驻、托盘、关闭窗口隐藏、暂停/继续、立即检测、间隔、启动项、离线/恢复/休眠记录。
- 保留并兼容旧 NetworkWatch 数据，发布包包含运行时，不依赖用户安装 Python。
- 公开仓库和发布内容仅包含源代码、原创生成美术、演示数据与文档。实测 IP、代理账号、本机配置与日志不提交。
- 默认不启用开机启动、不改变系统代理或 VPN。
